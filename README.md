# Java Prácticas

Repositorio personal para el aprendizaje y práctica de Java.

## Curso base

Curso de Java para principiantes de MoureDev.

## Stack

- Java 25
- IntelliJ IDEA
- Ubuntu WSL
- Maven
- Git
- GitHub

## Organización

Las prácticas están organizadas por temas dentro de:

src/main/java/com/magodev/mouredev/

Ejemplo:

- tema01
- tema02
- tema03
- ...

Cada tema contiene el código desarrollado durante la clase y los ejercicios correspondientes.
